## 最近一轮重大变更（2026-10-01 引擎压测修复轮）

1. **Actix 适配层三大能力补齐**：
   - **Arbiter 池**：`ActixActorSystem` 内置多 arbiter（默认 CPU 数），spawn round-robin 分配 → 跨 actor 真并行（64 actor CPU 吞吐 939/s → 11,096/s）
   - **异步 handler**：`Handler` 改为 `AtomicResponse` 双路径——同步快路径（默认，零开销）+ 异步路径（`use_async_handler() == true` 启用，handler 内可 `.await`，actor 串行语义由 actix `ctx.wait` 门控保证）
   - **队头阻塞消除**：饥饿测试 max 5,271ms → 0.13ms
2. **actix path 唯一化**：spawn 路径追加 uuid 后缀，同类型多实例不再覆盖注册表（herd-20000 验证）
3. **双引擎语义对齐**：thread 引擎 `send` 桥接真实 ask；actix `stop()` 拦截修复（详见 03 §2/§3 状态标注）
4. **压测规模对齐 akka 级**：CPU 并行 64 actor、herd 20,000、IO 64 actor × 1,280 任务
